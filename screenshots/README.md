# Screenshots

Add screenshots here as PNG files:

- `server.png` — Server tab (server control, settings, log viewer)
- `player.png` — Player tab (rank card, medals, kill feed, dashboard)
- `community.png` — Community tab (Reddit feed, Steam discussions, GitHub card)
- `setup.png` — Setup wizard

**How to take them:** Run the app, open http://127.0.0.1:3000, and use your browser's screenshot tool or Windows Snipping Tool (Win+Shift+S).

Recommended size: 1280×800px or similar 16:9 ratio.
