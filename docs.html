1 Concept & Idea

Insurgency: Sandstorm has a dedicated server tool that lets you host matches on your own PC — complete with bots, custom settings, and full control over the experience. However, managing it has always meant editing INI files by hand, running commands in a terminal, and keeping track of log files yourself.

Insurgency Sandstorm Local Server Manager wraps all of that into a clean, browser-based interface that runs locally on your machine. You open http://127.0.0.1:3000 in your browser, and from there you can start and stop your server, tweak every gameplay setting, watch the live log — and also track your own performance with a full rank and medal system.

Who is this for? Players who run a local dedicated server on their own PC, primarily for solo or LAN play with friendly bots. The app is designed for local use only — it does not include authentication, so it should not be exposed on the internet.

3 Installation

Download or clone the project

Download from GitHub as a ZIP and extract it, or clone with Git:

git clone https://github.com/Ans777/insurgency-sandstorm-server-manager.git

Install dependencies

Open a terminal in the project folder and run:

npm install

Start the manager

On Windows, double-click start.bat. Or from the terminal:

node server.js

Run the setup wizard

Your browser will open automatically to http://127.0.0.1:3000. If no config exists yet, the setup wizard starts. Fill in your paths and optional tokens — the app will auto-detect Steam if installed in a standard location.

4 Configuration

All settings are stored in config.json in the project folder. This file is created automatically by the setup wizard and is excluded from Git (it contains your personal paths and tokens).

{
  "language":    "en",          // UI language: "en" or "da"
  "managerPort": 3000,          // Port the web interface runs on
  "steamDir":    "D:\\Steam",   // Path to your Steam installation
  "serverDir":   "D:\\Steam\\steamapps\\common\\sandstorm_server",
  "gameDir":     "D:\\Steam\\steamapps\\common\\sandstorm",
  "playerName":  "",            // Auto-detected from server log on first login
  "steamId":     "",            // Auto-detected from Steam userdata folder
  "gsltToken":   "",            // Game Server Login Token (see below)
  "openaiKey":   "",            // OpenAI API key for AI assistant
  "port":        27102,         // Server game port
  "queryPort":   27131          // Server query port
}

GSLT Token

A Game Server Login Token (GSLT) allows your player name to appear in the app and enables XP rewards. Without it, the app shows "Player" as your name and kill tracking still works, but you won't see your rank name from Steam.

Go to Steam Game Server Account Management

steamcommunity.com/dev/managegameservers

Create a new token

Enter App ID 581320 (the game, not the dedicated server tool). Add a memo like "local server".

Paste the token

Enter it in the setup wizard or directly in config.json under "gsltToken".

Note: Steam requires that you own Insurgency: Sandstorm to create a GSLT. If your account doesn't own the game, the token creation will fail.

Adding More Languages

Copy lang/en.json to lang/xx.json (where xx is the language code, e.g. fr for French) and translate the values. Then select your language in the setup wizard or set "language": "xx" in config.json.

5 Using the App

The app is divided into five tabs, each covering a different area. Here is what each tab does and how to use it.

Server

The main control panel for your dedicated server. From here you can:

  • Start / Stop the dedicated server process. Use "Dedicated + Connect" to start the server and immediately launch the game client to join it.
  • Select map, game mode, and side for the next server start.
  • Quick Settings — adjust bot counts, difficulty, supply, respawn waves and more without editing INI files. Changes are written to Game.ini and take effect on the next server start.
  • Mutators — toggle special game modes like Frenzy, Vampirism, or BulletSponge.
  • Presets — save your favourite configurations and load them with one click.
  • MapCycle editor — define the map rotation for longer sessions.
  • Game.ini editor — full manual access to the config file with backup and restore.
  • Mod Manager — browse and toggle installed mod.io mods.
  • Server Log — live log viewer with search, filters, and RCON console.
Auto-restart: Check the "Auto-restart" box to have the manager automatically restart the server if it crashes. Useful for long overnight sessions.
Player

Your personal statistics and gamification panel. Kill tracking is done via the server log — only your kills count, not bot kills or other players.

  • Rank & Career — 12 military ranks from Recruit to Field Marshal, based on total kills.
  • Medals — 37+ medals for kill milestones, streaks, weapon mastery, and map mastery.
  • Challenges — pick from a list of challenges (e.g. "Get 10 kills with a pistol"). Daily challenges auto-rotate.
  • Kill Feed — live feed of kills and deaths with weapon info and color coding.
  • Dashboard — session performance graph, activity heatmap by hour, K/D per map and per weapon.
  • Achievements — your Steam achievements with unlock status and progress.
Getting kill tracking to work: The server must be started with the -LogCmds="LogGameplayEvents Log" parameter, which the app adds automatically. Your player name is detected from the server log the first time you connect.
Global Stats

Live data from Steam about Insurgency: Sandstorm as a whole.

  • Current number of players online worldwide.
  • Your stats compared to the global average — see how your achievement progress stacks up against all players.
News

Latest news and patch notes from New World Interactive, fetched directly from the Steam news feed. Cached for 10 minutes to avoid unnecessary API calls.

Community

Stay connected with the Insurgency community without leaving the app.

  • Reddit — top posts from r/insurgency, updated every 5 minutes. Click any post to open it in your browser.
  • Steam Discussions — latest threads from the Steam Community Hub.
  • GitHub — link to the project repository. If you find the app useful, a ⭐ on GitHub helps others discover it!
AI Assistant

A floating panel accessible from any tab via the brain icon in the bottom-right corner. Requires an OpenAI API key.

  • Voice input — hold the microphone button to speak.
  • Text input — type your question and press Enter or Send.
  • Specialized in Sandstorm server admin: Game.ini settings, bot configuration, maps, mods, and more.

7 Tips & Tricks

Getting the most out of kill tracking

Kill tracking relies on LogGameplayEvents in the server log. The app adds the required launch parameter automatically. Your name is detected on first connect. If it shows "Player" instead of your name, make sure your GSLT token is correct and that you are not running with -nosteam.

Using presets for different sessions

Save a preset for each type of session you like to play — e.g. "Hardcore solo", "Bot horde", "Relaxed co-op". Load them with one click without having to re-configure everything.

Exporting your stats

In the Player tab → Dashboard, click "Export Stats" to save a PNG image of your career summary — rank, K/D, medals, and top maps. Useful for sharing on Discord or Reddit.

RCON commands

The RCON console in the Server Log panel lets you send live commands to the running server. Useful commands:

CommandEffect
listplayersShow connected players
travel MapName?Scenario=...?Game=...Change map immediately
kick PlayerNameKick a player
say Hello!Send a chat message to all players

Mutator combinations worth trying

  • Frenzy + BulletSponge — zombie horde that takes many bullets to kill. Very intense.
  • Vampirism + HardcoreCheckpoint — no HUD, stay alive by killing enemies. High skill challenge.
  • AllYouCanEat + BoltActionsOnly — unlimited supply but bolt-actions only. Tactical sniper mode.

8 FAQ

The server starts but I can't connect to it

Use the "Dedicated + Connect" button which starts the server and launches the game client with the correct connection parameters. If connecting manually, use open 127.0.0.1:27102 in the game console.

My kills are not being tracked

Make sure you started the server via the app (it adds the required -LogCmds parameter). Also check that your player name has been detected — it appears in the header area. If it shows "Player", reconnect to the server once while it is running.

The app shows "Stoppet" but the server is still running

If the server was started outside the app (e.g. manually), the app won't know about it. Always use the app's Start Server button for tracked sessions.

Can I use this if my server is on another machine?

Not fully. The app manages the server process directly and reads log files from the local filesystem. The RCON console would work over a network, but starting/stopping and config editing require local access. It is designed for the case where server and client are on the same PC.

How do I add a new language?

Copy lang/en.json to lang/xx.json, translate the values, and set "language": "xx" in config.json. All UI elements will update automatically on the next app start.

Is it safe to expose this on the internet?

No. The app has no authentication. Only use it on localhost or a trusted local network. If you need remote access, put it behind a reverse proxy (nginx/Caddy) with HTTPS and basic authentication.
